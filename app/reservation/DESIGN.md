# VR大空间 - 用户端预约 redesign 设计文档

> 参考风格：沉浸世界 VR 小程序（深色科技风）
> 目标：将现有 4 步场地预约流程，升级为更符合 VR 消费场景的沉浸式预订体验

---

## 一、设计系统

### 色彩
| Token | 色值 | 用途 |
|---|---|---|
| `--bg-primary` | `#0a0e27` | 页面主背景（深蓝黑） |
| `--bg-card` | `rgba(20, 26, 60, 0.8)` | 卡片背景 |
| `--bg-elevated` | `rgba(30, 38, 80, 0.6)` | 浮层/弹窗背景 |
| `--accent-primary` | `#6366f1` | 主品牌色（靛蓝紫） |
| `--accent-secondary` | `#8b5cf6` | 强调色（紫色） |
| `--accent-gradient` | `linear-gradient(135deg, #6366f1, #8b5cf6)` | 渐变按钮 |
| `--text-primary` | `#ffffff` | 主文字 |
| `--text-secondary` | `rgba(255,255,255,0.6)` | 次要文字 |
| `--text-muted` | `rgba(255,255,255,0.35)` | 辅助文字 |
| `--border-subtle` | `rgba(255,255,255,0.08)` | 卡片边框 |
| `--success` | `#10b981` | 可预约/成功态 |
| `--warning` | `#f59e0b` | 警示态 |
| `--error` | `#ef4444` | 错误态 |

### 字体
- 主字体：`PingFang SC`, `Noto Sans SC`, sans-serif
- 数字用等宽或更紧凑的字体

### 圆角
- 卡片：`16px`
- 按钮：`12px`（大按钮） / `9999px`（标签/徽章）
- 输入框：`12px`

### 阴影/光效
- 卡片：`0 4px 20px rgba(99, 102, 241, 0.1)`
- 选中态：外发光 `0 0 16px rgba(99, 102, 241, 0.3)`
- 按钮渐变 + 微光扫过动画

## 二、信息架构调整

现有流程是"选场地 → 选时间 → 填信息 → 支付"，新设计将**场地与游戏内容绑定**，改为：

```
首页（场地/游戏列表）
  └─ 场地详情页（场地介绍 + 可选时段入口）
       └─ 时间选择弹窗（日期 + 场次列表）
            └─ 订单确认页（人数 + 信息 + 支付）
                 └─ 支付成功页
```

> 核心变化：场地不再是纯"房间"概念，而是带有主题/游戏内容的**体验产品**。

## 四、底部 Tab 导航（新增）

```
┌──────┬─────────┬──────┬──────┐
│  🏠  │   🎮   │  📋  │  👤  │
│ 首页 │ 游戏-门店│ 订单 │ 我的 │
```

- **首页**：场地/游戏卡片列表

## 五、关键交互与动效

| 场景 | 动效 |
|---|---|
| 页面进入 | 从右向左滑入（0.3s ease-out） |
| 弹窗出现 | 底部向上滑出（0.25s ease-out） |
| 卡片悬停/触摸 | 微微放大 + 紫色外发光 |
| 按钮点击 | 缩放 0.97 + 涟漪效果 |
| 加载中 | 骨架屏或紫色脉冲动画 |
| 成功页 | 勾选画圈动画 + 内容依次淡入 |
| 标签切换 | 下划线滑动过渡 |

## 六、数据流（保持现有 API 不变）

```
首页场地列表    → GET /venues
场地详情        → GET /venues/:id
时间选择-已有预约 → GET /bookings?venueId=&date=
创建预约        → POST /bookings
创建订单        → POST /orders
订单列表        → GET /orders?status=
```

> 所有现有 API 均可复用，无需后端修改。

## 七、MVP 排期建议

| 阶段 | 内容 | 优先级 |
|---|---|---|
| P0 | 首页场地列表 + 场地详情 + 时间选择弹窗 + 订单确认 + 成功页 | 必须 |
