# Triage Labels

工程技能内部使用五个标准 triage 角色。本文件将这些标准角色映射到本项目 GitHub Issues 中实际使用的中文标签。

| Skill 标准角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待评估` | 需要维护者先判断问题性质、优先级和处理方式 |
| `needs-info` | `待补充信息` | 当前信息不足，需要报告人或业务方补充 |
| `ready-for-agent` | `可交给Agent` | 描述完整，验收清楚，Agent 可以独立处理 |
| `ready-for-human` | `需人工处理` | 需要人工判断、业务拍板或线下处理 |
| `wontfix` | `不处理` | 明确不处理或暂不纳入当前范围 |

当技能提到标准角色时，使用右侧中文标签。不要额外创建英文重复标签。
