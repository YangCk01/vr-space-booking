# C 端小程序 UI 改造方案（参考 Cotti Coffee）

> 状态：方案稿，待评审后再进入开发  
> 范围：`app/reservation`（React + Vite + Tailwind CSS）

## 1. 现状与问题

当前 C 端首页以紫/蓝色渐变为主，信息模块堆叠较密，视觉重心分散：

- 顶部定位、搜索、通知各自独立，缺乏一体化头部
- Banner、VIP、团购、热门体验模块间距和圆角不统一
- 商品/游戏列表以纵向大卡片为主，点击区域分散
- 缺乏“到店体验 / 在线预约”等主行动入口的显性表达
- 整体色彩偏暗，与年轻、潮玩、科技感的 VR 大空间定位略有偏差

## 2. 参考设计解析（Cotti Coffee）

从参考截图可提炼出以下可借鉴的设计语言：

| 设计元素 | Cotti Coffee 做法 | 可借鉴点 |
|---------|------------------|---------|
| **色彩** | 天蓝（品牌主色）+ 白色底色 + 红/金促销点缀 | 改用更清新、高饱和的品牌蓝；减少深色渐变，增加留白 |
| **顶部** | 定位胶囊 + 扫一扫 + 更多按钮，一体化 | 将定位、语言、通知合并为更轻量的顶部栏 |
| **Banner** | 全宽大图、圆角 16px、人物/产品主视觉、左对齐文案 | 保持全宽 Banner，但增加呼吸感，标题更克制 |
| **入口区** | “到店自取 / 外卖配送”两个大卡片 + 4 列宫格 icon | 把“选择门店 / 立即预约”做成显性的双主入口；分类用圆角大图标宫格 |
| **营销区** | 两列卡片网格、左侧大图、右侧促销文案 | 团购/活动用左图右文或上图下文网格，减少横向滚动 |
| **点餐页** | 左侧分类锚点 + 右侧商品卡片、商品大图、价格、加购按钮 | 门店详情页可改为“游戏分类 + 游戏卡片 + 预约按钮” |
| **商品详情** | 顶部大图、规格选择按钮组、底部固定购买栏 | 游戏详情/套餐页用弹窗或底部固定栏做人数/场次选择 |
| **订单** | 取餐码大字、门店信息、商品卡片、再来一单 | 订单列表突出取餐/入场码，减少信息密度 |
| **我的** | 会员头部、代金券/优惠券数字、功能列表 | 个人中心强化会员等级、余额、优惠券资产 |

## 3. 改造原则

1. **清新科技，弱化厚重感**：用品牌蓝 + 白底替代大面积紫黑渐变，卡片用浅灰/浅蓝背景区分层次。
2. **主入口显性化**：首页首屏聚焦“选门店”和“选游戏/预约”两个核心动作。
3. **信息分层**：Banner → 主入口 → 营销区 → 热门列表，纵向节奏清晰。
4. **组件复用**：新建/改造 3-4 个通用组件（入口卡片、商品卡片、规格选择器、底部固定栏），覆盖首页、门店页、详情页、订单页。
5. **不动业务逻辑**：仅改样式和布局，不改路由、API、场次计算、支付流程。

## 5. 分页面改造方案

### 5.1 首页 `Home.tsx`

参考 Cotti 首页结构重新排布模块顺序：

```
┌─────────────────────────────┐
│ 顶部栏：定位 | 语言/通知胶囊        │
├─────────────────────────────┤
│ 搜索条（圆角胶囊，弱化边框）        │
├─────────────────────────────┤
│ Banner 轮播（全宽、圆角 16、渐变文字）│
├─────────────────────────────┤
│ 双主入口卡片：                       │
│  [到店体验]        [在线预约/拼场]    │
├─────────────────────────────┤
│ 4 列宫格分类（icon + 标签）          │
├─────────────────────────────┤
│ VIP / 会员储值横条                   │
├─────────────────────────────┤
│ 团购推荐：两列网格卡片               │
├─────────────────────────────┤
│ 热门体验：横向滑动 or 纵向列表        │
└─────────────────────────────┘
```

**关键改动：**

- 顶部栏：左侧 `MapPin + 门店名 + ChevronRight` 合并为一个胶囊按钮；右侧语言切换和通知合并为两个圆形 icon 按钮。
- 双主入口：用两张 1:1 的大圆角卡片，左侧“到店体验”配门店图，右侧“在线预约/拼场”配游戏图，提升首屏点击欲望。
- 宫格分类：4 列圆角图标，icon 尺寸 44×44，背景用 `--bg-elevated` 浅蓝，替代当前小图标。
- 团购区：由横向滚动改为 2 列网格，卡片高度统一，左侧大图 + 右侧价格/标签。
- 热门体验：保持纵向卡片，但改用“左图右信息”紧凑布局，价格用品牌蓝，原价用删除线灰色，预约按钮用品牌蓝实心小按钮。

### 5.2 门店/体验页 `VenueDetail.tsx`

参考 Cotti “点餐页”布局：

```
┌─────────────────────────────┐
│ 顶部：自取/体验 切换 + 搜索框       │
├─────────────────────────────┤
│ 门店信息卡片（距离/地址/营业时间）    │
├─────────────────────────────┤
│ 左侧分类导航 | 右侧游戏列表          │
│  全部          [游戏卡片]           │
│  冒险          [游戏卡片]           │
│  科幻          [游戏卡片]           │
├─────────────────────────────┤
│ 底部固定：优惠券悬浮球 + 购物车条     │
└─────────────────────────────┘
```

**关键改动：**

- 左侧分类导航固定，右侧游戏列表滚动（参考 Cotti 点餐页）。
- 游戏卡片：大图（80×80 圆角）、标题、副标题、标签（时长/人数）、价格、加购/预约按钮。
- 已选场次在底部以悬浮条展示，与 Cotti 底部“去结算”一致。

### 5.3 游戏详情/套餐页 `GameDetail.tsx`

参考 Cotti 商品详情：

```
┌─────────────────────────────┐
│ 返回 | 标题 | 更多              │
├─────────────────────────────┤
│ 大图 Banner（可左右滑动）         │
├─────────────────────────────┤
│ 游戏名 + 副标题 + 评分/人数        │
├─────────────────────────────┤

│  人数：1人 / 2人 / 3人 / 包场      │

├─────────────────────────────┤
│ 游戏介绍 / 须知 / 设备说明          │
├─────────────────────────────┤
│ 底部固定：价格 + 立即预约           │
└─────────────────────────────┘
```

**关键改动：**

- 顶部返回按钮改为透明悬浮在 Banner 上。
- 人数/场次选择用 Cotti 式圆角按钮组，选中态为品牌蓝边框 + 浅蓝底。
- 底部固定栏：左侧显示“¥xx 起”，右侧“立即预约”品牌蓝大按钮。

## 8. 风险与注意事项

- **不动业务逻辑**：场次计算、库存判断、支付流程保持原样，只改渲染层。
- **图片素材**：Cotti 风格依赖高质量 Banner 和游戏封面图，需准备 16:9 或 1:1 统一尺寸素材。
- **底部导航**：当前为“首页 / 体验 / 订单 / 我的”，可保留；如参考 Cotti 增加“潮玩/团购”独立 Tab，需评估必要性。
- **性能**：左分类右列表布局在低端机上需做长列表优化（虚拟滚动或分页）。
